
# Student Management System 

This project is developed using Java, JDBC, JFrame, and MySQL. The main goal of this project is to manage student information efficiently.”


## Project Objectives

Student Data সংরক্ষণ করো।

 Database এর সোযে Java সং ুক্ত করো।

CRUD Operation িোস্তিো়েন করো।

 User Friendly Interface ত ডর করো।

 JTable এর মোধ্যযম Data প্রদ্র্ শন করো
